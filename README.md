# Pharma-Pipeline: 100 Aktien

Übersicht über 100 Pharma-Unternehmen mit ihren wichtigsten Studien und der jeweiligen Phase. Suche, Phasenfilter, Merkliste und eigene Kurse (im Browser gespeichert).

Öffnen: `index.html` im Browser, oder über GitHub Pages veröffentlichen.

Jede Studie zeigt das letzte und das nächste Ereignis (Quartal/Halbjahr). Datenstand: Web-Recherche Oktober 2026, keine Anlageberatung.

## Krypto-Liquidationen

Live-Board unter `liquidationen/`: Zwangsliquidierungen von Binance, Bybit und OKX (Longs/Shorts, Top-Coins, Live-Feed, größte Liquidationen). Daten kommen direkt aus den öffentlichen Börsen-Streams.
